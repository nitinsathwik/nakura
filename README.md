# Nakura Industries Private Limited — Official Website

> **Together Power a Greener Future**

Official landing page for **Nakura Industries Pvt. Ltd.**, a UCO (Used Cooking Oil) Aggregator company based in Visakhapatnam, Andhra Pradesh, India.

---

## 🌿 About

Nakura Industries collects Used Cooking Oil from restaurants, hotels, canteens, and food establishments, and supplies it to biodiesel and Sustainable Aviation Fuel (SAF) producers — turning waste into clean energy.

---

## 📁 Project Structure

```
nakura-website/
├── index.html        # Main landing page (all-in-one: HTML + CSS + JS)
└── README.md         # Project documentation
```

> The entire website is a **single self-contained HTML file** — no dependencies, no build tools, no frameworks required. The logo is embedded as a base64 PNG directly in the HTML.

---

## 🚀 Deployment

### GitHub Pages (Recommended)

1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch, `/ (root)` folder
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`

### Direct Hosting

Simply upload `index.html` to any static hosting provider:
- GitHub Pages
- Netlify (drag & drop)
- Vercel
- Any web server (Apache / Nginx)
